# nobl-motion

On-brand motion graphics (YouTube, reels, website) made with HyperFrames
(HTML + GSAP + Three.js → MP4): **technical** (charts, 3D colour spaces) and
**artistic** (camera, film, light, darkroom). Part of `lucas-os`; the owner is
a colour scientist, so small details and colour accuracy matter.

## Where things live

- `brand/`: `tokens.css` (all values), `motion.md`, `signatures.md`, and
  `reference/` (brand card, colour check).
- `components/COMPONENTS.md` index of components (JS modules), one line each.
- `scenes/<video>/<scene>/` `spec.md`, `index.html`, `data/`.
- `scripts/stage.mjs`, `render.mjs`, `colour_check.py`. `renders/` (gitignored).

**Staging.** HyperFrames' check/snapshot/preview/render work on the root
`index.html` only, so `node scripts/stage.mjs <dir> [9x16]` copies a
composition there at that size (generated, gitignored; never edit it). Paths in
compositions are written from the repo root: `brand/tokens.css`,
`./scenes/<video>/<scene>/data/x.json`. Edits made in the HyperFrames app
land in the root copy: `node scripts/stage.mjs --pull` puts them back.

**Reading order, cheapest first:** this file → `brand/tokens.css` +
`brand/motion.md` → `components/COMPONENTS.md` → only the scene or component
files the task touches. Never load other scenes' code wholesale; grep them.

## Rules

- **No hard-coded colours, fonts, easings or durations** in scenes or
  components. Everything comes from `brand/tokens.css` (`var(--…)` in CSS;
  `getComputedStyle` in JS). A missing token is added to `tokens.css` first.
- **One file, three ratios.** Every composition works at 16:9, 9:16 and 1:1.
  Author at 1920×1080; size everything with container units (`cqw`, `cqh`,
  `cqmin`) on a `container-type: size` root, and read the size in JS from the
  root's `data-width`/`data-height`. Never make per-ratio copies by hand.
- **Render** 1920 long edge by default, 3840 when asked, only via the `render` skill.
- **Data** for technical scenes comes from JSON in the scene's `data/`
  (generated by `lucas-os/scripts` or in place), imported as a JSON module.
  Never type numbers into a composition.
- **Colour accuracy is non-negotiable.** Delivery is Rec.709 SDR with no grading
  after it: sRGB code values pass through unchanged and are tagged bt709. Every
  render's tags are checked; the patch check must pass (see `render` skill).
- **The second appearance makes a component** (`new-scene`, `promote-component`).
- Deterministic only: no `Date.now()`, unseeded `Math.random()`, network
  fetches, timers or infinite repeats. Run `npm run check` after every edit.
- No `hyperframes feedback` reports or `publish` unless Lucas asks.
